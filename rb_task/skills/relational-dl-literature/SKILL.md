- Search from 2010 onwards: the field is broad (graph neural networks, learning on relational databases, tabular
  deep learning); write your own queries from the research topic and the problem decomposition.
- Prefer papers with arXiv versions (the full text can be read) and official code (it can be ported).
- Screen out surveys without methods, other domains (chemistry, neuroscience, code) and papers without implementable components.
